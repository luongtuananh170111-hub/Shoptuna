# TUNA DEMO SHOP — PWA

Bản PWA dành cho iPhone. Có manifest, icon, chế độ standalone và service worker.

## Cài trên iPhone
PWA cần được mở từ một địa chỉ HTTPS (không cài PWA hoàn chỉnh từ file ZIP/file://).
Sau khi đưa project lên một hosting HTTPS:
1. Mở trang bằng Safari.
2. Bấm Chia sẻ.
3. Chọn **Thêm vào Màn hình chính**.
4. Mở icon TUNA SHOP như một app.

## Chạy/đưa lên hosting
`npm install`
`npm run dev`

Hoặc build bằng `npm run build` rồi đưa thư mục `dist` lên hosting tĩnh hỗ trợ HTTPS.

Mọi số dư, nạp và BXH trong app đều là DEMO/simulation.
